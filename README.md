# AI开工助手

开工查网络，收工查残留。

**[下载 Windows 11 x64 便携版及源码包](https://github.com/Moonlala5689/ai-workday-assistant/releases/tag/v0.1.0-beta.1)**

AI开工助手是一款 Windows 连接观察工具：开工时检查本次 IPv4 出口、DNS 和指定 AI 服务的加密连接；收工时只读检查部分工作应用和后台服务是否仍有候选。检查详情还包括 IPv6 和隔离浏览器的 WebRTC 观察。

当前版本：**0.1.0-beta.1**，Windows 11 x64 便携版。请完整解压后，双击 `AI开工助手.exe`，点击“一键开始办公”。固定 IPv4 核对是可选项。需要离开时，点“一键结束办公”；程序不会替你结束工作软件。关闭窗口会收进托盘，完全退出请使用页面底部或托盘菜单。

网络连通分只衡量本轮指定的 IPv4 双源、DNS 和 AI 服务直接加密连接；未知项以待测或范围显示。它不是 IP 信誉、账号风险或全部流量安全评分。服务登录、模型响应、其他应用及所有网络路径均须单独核对。IPv6 或浏览器检查未完成时，相应卡片会说明，不能据此推断已关闭或没有泄漏。

出口地区与运营商信息使用随包提供的 DB-IP Lite 2026-11 数据，仅供参考；覆盖、准确性和时效均有限，不提供住宅或机房分类。本版本尚未代码签名，Windows 可能显示下载或运行提示；请从你信任的发布位置获取并核对 SHA-256。跨设备、长期运行、所有浏览器和所有网络环境尚未充分验证。详细说明见 `快速开始.md`、`隐私与网络.md`、`已知限制.md`。

## 从源码构建

已在 Windows 11 x64 使用 PowerShell 7.6.9 和系统 .NET Framework x64 `csc.exe` 验证构建。编译器位置为 `%WINDIR%\Microsoft.NET\Framework64\v4.0.30319\csc.exe`；其他 PowerShell 版本和工具链尚未验证。解压源码后，在源码根目录运行：

```powershell
.\build-consumer.ps1
```

程序输出到 `build\consumer\`。源码构建的字节哈希可能因编译环境和时间不同而变化；发布包的哈希以发布页提供的清单为准。
